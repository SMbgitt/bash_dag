# Морской Бой (Battleship) на Bash

Клиент-серверная игра «Морской бой», написанная на чистом Bash.

## Архитектура
* **Сервер (`server.sh`):** Единственное место, где существует состояние игры, координаты кораблей, сетка 10×10 и проверка попаданий. Клиенту передается только готовый ANSI-интерфейс.
* **Клиент (`client.sh`):** Тонкий клиент без состояния. Обеспечивает мгновенный ввод/вывод (<1 мс) без буферизации.
* **Режимы:**
  1. `1 на 1 (Игрок против Игрока)` — по сети через два терминала.
  2. `1 на 1 (Игрок против Бота)` — с умным алгоритмом поиска (Hunt & Target).

---

## Способы расстановки флота
Каждый игрок может выбрать:
1. **[1] Автоматически:** сервер моментально генерирует классический флот (1x4, 2x3, 3x2, 4x1) с гарантией расстояния в 1 клетку между кораблями.
2. **[2] Вручную:** пошаговая расстановка каждого корабля с отрисовкой поля на каждом шаге.
   * Формат ввода для многопалубных: `B3 H` (горизонтально вправо) или `B3 V` (вертикально вниз).
   * Формат для 1-палубных: просто клетка, например `E5`.
   * Поддерживается как английская (`H`, `V`), так и русская раскладка (`Г` - горизонт, `В` - вертик).

## Быстрый запуск

### 1. Откройте WSL
В терминале:
```bash
wsl
cd /mnt/c/Users/01234/Desktop/Programming/bash_dag
```

### Игра против Бота:
1. Терминал 1 (Сервер):
   ```bash
   ./server.sh
   ```
   Выберите `[2]` (Человек против Бота).

2. Терминал 2 (Клиент):
   ```bash
   ./client.sh
   ```

### Игра вдвоем (1 на 1):
1. Терминал 1 (Сервер):
   ```bash
   ./server.sh
   ```
   Выберите `[1]`.

2. Терминал 2 (Игрок 1):
   ```bash
   ./client.sh 1
   ```

3. Терминал 3 (Игрок 2):
   ```bash
   ./client.sh 2
   ```
